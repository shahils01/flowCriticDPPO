## STABLE PPO

This repository provides a clean and stable version of PPO, which works for high-dimensional state and action space environments such as "Humanoid-v4". Test results will be posted soon. 

The code of our latest work, "Generalized Advantage Estimation for Distributional Policy Gradients," will be integrated soon as well. Meanwhile, please find our paper at: https://arxiv.org/abs/2507.17530
